# Glosario breve de Ozi Ozi

Las entradas de este glosario resumen el vocabulario **propuesto en la enciclopedia**. No son afirmaciones de que exista una lengua independiente o una etimología antigua comprobada.

| Término | Significado en este proyecto |
|---|---|
| **Ozi Ozi** | Expresión repetida y concepto cultural abierto; su sentido depende del contexto. |
| **Ozi** | Una unidad de la repetición; puede leerse poéticamente como una invitación breve. |
| **Ozi-eco** | Respuesta que devuelve o reconoce un saludo. |
| **Ozi-pausa** | Espacio sin respuesta inmediata; no equivale por sí solo a rechazo ni aceptación. |
| **Oziar** | Verbo informal propuesto para usar Ozi Ozi o añadir un gesto de juego responsable. |
| **Oziado/a** | Adjetivo humorístico para algo con calidez o absurdo inesperados. |
| **Oziísmo** | Nombre propuesto para la filosofía de curiosidad, honestidad, creatividad y cuidado. |
| **Oziario** | Colección de usos, obras, fuentes, testimonios, variantes y relatos. |
| **Ozi-contexto** | Explicación local para que las personas nuevas entiendan un uso comunitario. |
| **Ozi-señal** | Marca visual, sonora o gestual adoptada por una comunidad concreta; no hay símbolo universal obligatorio. |
| **Ozi-documentado** | Afirmación cuya fuente puede revisarse; no significa certeza absoluta. |
| **Ozi-mito** | Relato imaginado y etiquetado expresamente como ficción. |
| **Ozi-cuidado** | Práctica de escuchar y respetar límites antes de insistir con humor. |
| **Ozi-ruido** | Exceso de bromas o variaciones que dificulta entender el mensaje principal. |

Consulta la [enciclopedia](ozi%20ozi.txt) para definiciones completas, ejemplos, variantes y límites de cada término.
